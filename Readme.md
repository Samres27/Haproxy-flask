## Introduction and Thanks
To create a lab, I had to research how to exploit the HTTP smuggling vulnerability and followed the steps in: https://gist.github.com/ndavison/4c69a2c164b2125cd6685b7d5a3c135b.

I am very grateful to the author of that publication and am sharing this repository with the lab explained in the article. This vulnerability is more technical than logical, so the lab was designed for Python 3.9, but theoretically it works with Python 3.6-3.9.
